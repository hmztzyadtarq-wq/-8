# حلو الملك — 8 ملفات في فولدر واحد (من غير فولدرات)

الموقع: `index.html` + `style.css` + `script.js`
اللوحة: `admin.html` + `admin.css` + `admin.js`
`firestore.rules`: بتتنسخ وتتلصق في Firebase ← Firestore ← Rules ← Publish (مش جزء من الموقع).
`README.md`: الملف ده.

## خطوات الرفع (بالترتيب)
1. **الأول** انسخ `firestore.rules` والصقه في Firebase ← Firestore Database ← Rules ← Publish.
2. ارفع الـ 6 ملفات (index.html / style.css / script.js / admin.html / admin.css / admin.js) مكان القديم.
3. ادخل اللوحة ← **الولاء والنقاط** ← اضبط معدل النقاط والمكافآت والمستويات واحفظ.
4. (مرة واحدة، لو عندك طلبات قديمة اتسلّمت) الولاء والنقاط ← "إعادة حساب إحصائيات العملاء".
5. جرّب طلب كامل بنفسك قبل ما تعلن: سجّل حساب ← اطلب ← من اللوحة غيّر الحالة لـ "قيد التحضير" ثم "تم التسليم" ← شوف النقاط في حسابك.

## اللي اتغيّر

### توفير القراءات
- الموقع بيحمّل الأقسام والفروع والإعدادات + **منتجات الرئيسية اللي الأدمن اختارها بس** (الصفوف: الأكثر رواجًا / المنتجات الجديده / تشكيلة مميزة). مفيش صفوف من غير عنوان تاني.
- باقي المنتجات بتتحمّل لما الزائر يفتح القسم أو يبحث أو يفتح المنتج، وبتتخزن على جهازه.
- الزيارة المتكررة = **قراءة واحدة** (رقم النسخة) لو الأدمن مغيّرش حاجة. لو غيّر، البيانات بتتحدّث في الخلفية وبيظهر شريط "فيه تحديثات".
- البحث و"المنيو" بيحمّلوا كل المنتجات مرة واحدة (وبتتخزن). صفحة "عروض وخصومات" بتحمّل المنتجات اللي عليها خصم بس.
- المخزون والسعر بيتأكدوا من القاعدة وقت تأكيد الطلب (قراءة لكل صنف في السلة) عشان محدّش يطلب حاجة خلصت أو سعرها اتغيّر.
- لوحة الأدمن بتحمّل آخر 400 طلب بس (زرار "تحميل أقدم" + التقارير بتحمّل اللي محتاجاه لوحدها).
- تقدر تشوف في صفحة المنتجات عدد منتجات كل صف في الرئيسية (كل منتج في الرئيسية بيتحسب قراءة لكل زيارة أولى، فخلّيهم قليلين).

### حسابي (للعميل): `#/account`
طلباتي (+ "اطلب تاني") — نقاطي وكوبوناتي (رصيد، مستوى، مكافآت، كوبونات خاصة، كود دعوة) — عناويني (لحد 5) — المفضلة (متزامنة مع الحساب) — بياناتي (اسم، كلمة مرور، لغة).

### السلة
عناويني المحفوظة، ميعاد التوصيل، ملاحظات، رسالة هدية، شريط التوصيل المجاني، استبدال نقاط، خصومات تلقائية، حالة الفرع (مفتوح/مقفول)، شريط إعلان من الإعدادات، زرار مشاركة المنتج، "شاهدتها مؤخرًا".

### لوحة التحكم
- **الولاء والنقاط**: معدل الكسب، المكافآت، المستويات (خصم تلقائي)، التوصيل المجاني، مكافأة الدعوة.
- **العملاء**: أفضل العملاء، شرائح (VIP / نايمين / جدد / عندهم نقاط)، ملف العميل: إحصائيات، تعديل نقاط، خصم دائم %، كود خاص بالعميل، واتساب.
- **العروض**: نسبة / مبلغ / توصيل مجاني، تلقائي، ساعة سعيدة، أول طلب، مرة لكل عميل، حد استخدامات.
- الفروع: مواعيد فتح وقفل. الإعدادات: شريط إعلان.

### كيف تشتغل النقاط
- بتتضاف لما تغيّر حالة الطلب لـ **تم التسليم**.
- لما العميل يستبدل مكافأة، النقاط بتتخصم لما **تقبل الطلب** (تغيّره من "جديدة")، وبترجع لو اتلغى.
- العميل مقدرش يعدّل نقاطه (القواعد بتمنع)، والقواعد بتمنع طلب يستبدل نقاط أكتر من رصيده.

## ملاحظات مهمة
- حسابات الخصم بتحصل في متصفح العميل (زي الكوبون قبل كده)، فراجع الخصم في تفاصيل الطلب. الحماية الكاملة محتاجة Cloud Functions.
- لو غيّرت أسماء صفوف الرئيسية في `admin.js` (HOME_SECTIONS) غيّرها كمان في `index.html` و`script.js` (SEC).
- التطبيق على الموبايل (PWA) والتقييمات مش موجودين.
